# 🎬 FE Capstone Project – Movie Search App

A movie search application built using **React** and the **OMDb API**. Users can search for movies by title and view detailed information about each movie.

## 🔍 Features

- **Search Movies by Title**  
  Enter a movie name to retrieve a list of matching results from the OMDb API.

- **View Movie Details**  
  Click on a movie to see its full details, such as:
  - Title
  - Poster
  - Genre
  - Plot
  - Actors
  - Release Year
  - Runtime
  - IMDb Rating

## 🧰 Technologies Used

- ⚛️ React  
- 🎞️ OMDb API ([https://www.omdbapi.com](https://www.omdbapi.com))  
- 💅 Tailwind Css
